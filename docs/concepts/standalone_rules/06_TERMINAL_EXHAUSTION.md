# Rule 6 — Terminal Exhaustion (The Reversal Signal)

> **H4 counter-zone beyond broken D level = terminal.**
> This is the highest-level mechanical reversal signal in the system.

---

## The Rule

```
BEARISH TERMINAL:
  D demand breaks (close < D demand bot)  →  store broken D LL price
  H4 demand fires with bot < broken D LL  →  terminal_exhaustion_bear = TRUE

BULLISH TERMINAL:
  D supply breaks (close > D supply top)  →  store broken D HH price
  H4 supply fires with top > broken D HH  →  terminal_exhaustion_bull = TRUE
```

---

## The Checklist (All Must Be True)

### Bear Terminal (expect bullish reversal):

```
☐  D LL broken (daily structure bearish)
☐  H4 demand formed BELOW broken D LL
☐  5+ unbroken H1 supply zones overhead
☐  H1 wave count shows 5+3 pattern
→  Terminal exhaustion confirmed
```

### Bull Terminal (expect bearish reversal):

```
☐  D HH broken (daily structure bullish)
☐  H4 supply formed ABOVE broken D HH
☐  5+ unbroken H1 demand zones below
☐  H1 wave count shows 5+3 pattern
→  Terminal exhaustion confirmed
```

---

## H4 Zone Confirmation (Not "Live" Until Tested)

The H4 counter-zone is not live immediately. It must be confirmed:

```
1. H1 demand created at bottom (inside H4 demand)
2. Price pushes up → creates H1 supply (#8)
3. Price pushes back down → breaks that H1 demand
4. Pushdown reaches M15/M5 demand at the lowest point
5. → H4 demand is now CONFIRMED LIVE
```

**This is the break-retest cycle.** Until it completes, the H4 zone is provisional.

---

## What to Look For on Chart

**Three panels:**

1. **D panel:** Has D demand/supply broken? Mark the break price.
2. **H4 panel:** Has an H4 zone formed beyond that break price?
3. **H1 panel:** Count unbroken zones (5+ = impulse done, 8 = terminal)

**When all three align → TERMINAL → prepare for reversal entry.**

---

## Reset

Terminal exhaustion resets on:
- New D zone fires (D structure has changed)
- Macro bias flip

---

Terminal exhaustion is DETECTED early through:
```

H1 zone #6 forming (correction A wave) → reversal starting
H1 zone #8 inside H4 counter-zone → confirmed terminal
M15 CHoCH inside H1 #8 → earliest entry opportunity
```
