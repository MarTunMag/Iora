# Rule 1 — Zone Classification (HH / HL / LH / LL)

> **One rule, every timeframe, every zone.**
> This is the foundation everything else builds on.

---

## The Rule

When a new zone fires (HA color flip), compare it to the previous zone of the **same type** on the **same TF**:

### Supply Zone (blue → red flip)

```
New supply top > previous supply top  →  HH  (structural — trend continues)
New supply top ≤ previous supply top  →  LH  (corrective — trend weakening)
```

### Demand Zone (red → blue flip)

```
New demand bot < previous demand bot  →  LL  (structural — trend continues)
New demand bot ≥ previous demand bot  →  HL  (corrective — trend weakening)
```

---

## What It Creates One Level Up

| This TF zone event | Creates structure at parent TF |
|---------------------|-------------------------------|
| H1 HH | H4 HH (if top > prev H4 supply top) |
| H1 LL | H4 LL (if bot < prev H4 demand bot) |
| H1 LH | H4 LH (if top < prev H4 supply top) |
| H1 HL | H4 HL (if bot > prev H4 demand bot) |
| H4 HH/LH/HL/LL | D HH/LH/HL/LL (same comparison logic) |
| D HH/LH/HL/LL | W HH/LH/HL/LL (same comparison logic) |

---

## BOS vs CHoCH

When a zone **breaks** (close through it):

```
HH or LL zone breaks  →  BOS  (Break of Structure — trend confirmed)
LH or HL zone breaks  →  CHoCH (Change of Character — reversal signal)
```

**CHoCH is the early warning. BOS is the confirmation.**

---

## What to Look For on Chart

On any single TF panel, you only need to track:
1. Is the latest supply zone HH or LH?
2. Is the latest demand zone LL or HL?
3. When a zone breaks — is it BOS or CHoCH?

That's it. Everything else in the system is built from this.
