# Rule 9 — Boundary Zones (The Decision Box)

> **Boundary = last unbroken zone edge to structural extreme.**
> Break it = reversal confirmed. Respect it = trend continues.

---

## When It's Created

```
On H1 LL:  Boundary from H1 supply top (last unbroken) → down to H1 LL low
On H1 HH:  Boundary from H1 HH high → down to H1 demand bot (last unbroken)
```

Dotted internal line marks the original zone edge within the boundary box.

---

## The Decision

```
Bearish boundary (supply top → LL low):
  Close ABOVE supply top → boundary BROKEN → bearish structure invalidated
                         → H4 HH confirmed → reversal underway
  Price stays below     → boundary HOLDS → bearish trend intact

Bullish boundary (HH high → demand bot):
  Close BELOW demand bot → boundary BROKEN → bullish structure invalidated
                         → H4 LL confirmed → reversal underway
  Price stays above      → boundary HOLDS → bullish trend intact
```

---

## Visual


On break: boundary clips, orange tint applied.

---

## What to Look For on Chart

**H1 panel:**

1. Is there an active boundary zone? (the wide colored box)
2. Where is price relative to it?
3. Is price building structure inside it? (H1 zones forming = reversal building)

---

## Early Detection (Before the Break)

You don't have to wait for the boundary break itself. Inside the boundary zone:

```
H1 zones forming (building reversal structure)
  → M15 zones inside those H1 zones (refining direction)
    → M5 CHoCH inside M15 = boundary break is coming
      → M1 CHoCH = enter BEFORE the boundary visually breaks
```

**The boundary break is the HTF confirmation. The nested CHoCH inside it is the early entry.**

---

## Connection to H4 Supply/Demand Creation

The boundary zone is where the H4 supply (or demand) forms during reversal:

```
Terminal bottom:
  H4 demand confirmed below
  → Price pushes up into boundary zone (bearish boundary)
  → Boundary breaks → H4 HH → D LH
  → THEN: New H4 supply forms inside/near boundary zone
  → This H4 supply = reversal resistance = where Phase D push starts
```
