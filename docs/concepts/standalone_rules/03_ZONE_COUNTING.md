# Rule 3 — Zone Counting (5+3 Exhaustion)

> **Count unbroken zones. 5 = impulse done. 5+3 = terminal.**
> Same rule at every fractal level.

---

## The Count

Track **unbroken** zones of one type since the last parent TF zone reset:

```
Unbroken count < 5   →  Impulse active (trend has room)
Unbroken count = 5   →  Impulse exhausted (trend slowing)
Unbroken count = 5+3 →  Terminal exhaustion (reversal imminent)
```

---

## What to Count at Each Level

| What you count | Reset event | Exhaustion means |
|---------------|-------------|-----------------|
| H1 unbroken supply zones | New H4 supply fires, or H1 HH | H4 bearish push exhausted |
| H1 unbroken demand zones | New H4 demand fires, or H1 LL | H4 bullish push exhausted |
| M5 unbroken supply zones | New H1 supply fires | H1 bearish leg exhausted |
| M5 unbroken demand zones | New H1 demand fires | H1 bullish leg exhausted |
| M15 zones during pullback | Price exits H1 zone | Pullback exhausted |

---

## How to Read It on Chart

**One thing to look at per panel:**

- **H1 panel:** Count the unbroken supply zones overhead (or demand zones below). Number them 1-8.
- **M5 panel:** Count unbroken zones since last H1 zone fire. Same logic, one level down.

**The transition point:**

```
Zones 1-3:  Strong momentum, wide spacing     → TRADE WITH trend
Zones 4-5:  Deceleration, zones clustering     → PREPARE for reversal
Zone 6 (A): First counter-trend zone           → Correction starting
Zone 7 (B): Retest zone                        → "Perfect retest" possible
Zone 8 (C): Terminal — inside opposing HTF zone → WILL be broken, reversal HERE
```

---

## The Fractal Rule

This same 5+3 pattern repeats at every level:

```
5+3 M5 zones   = 1 H1 leg complete
5+3 M15 zones  = 1 H1 pullback complete
5+3 H1 zones   = 1 H4 reversal (terminal exhaustion)
H4 pushes      = D structure (HH/HL/LH/LL)
```

**When ALL levels show exhaustion simultaneously = FRACTAL DONE = highest conviction.**
