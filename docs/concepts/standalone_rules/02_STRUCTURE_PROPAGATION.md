# Rule 2 — Structure Propagation (Child Builds Parent)

> **How structure flows upward through the timeframe hierarchy.**
> Each TF's zones define the next TF's structure. No exceptions.

---

## The Universal Rule

```
Parent TF structure = comparison of Child TF zones
```

| Parent | Child zones compared | What you compare |
|--------|---------------------|-----------------|
| **W** | D supply tops / D demand bots | Sequential D zone comparisons |
| **D** | H4 supply tops / H4 demand bots | Sequential H4 zone comparisons |
| **H4** | H1 supply tops / H1 demand bots | Sequential H1 zone comparisons |
| **H1** | M15 supply tops / M15 demand bots | Sequential M15 zone comparisons |
| **M15** | M5 supply tops / M5 demand bots | Sequential M5 zone comparisons |

---

## How to Read It on Two Panels

**Panel 1 (child TF):** Watch zone sequence — HH/LH/HL/LL labels on each new zone.

**Panel 2 (parent TF):** The parent structure IS the child zone sequence.

### Example: Reading D structure from H4 panel

```
H4 supply #1 top: 1.2650  (first)
H4 supply #2 top: 1.2680  (higher → D HH)
H4 supply #3 top: 1.2640  (lower  → D LH) ← trend weakening
H4 demand #1 bot: 1.2500  (first)
H4 demand #2 bot: 1.2470  (lower  → D LL)
H4 demand #3 bot: 1.2490  (higher → D HL) ← potential reversal
```

---

## Streak Resets

When a new structural event fires, it resets the opposite counters:

```
HH fires → resets LH count to 0, resets LL count to 0
LL fires → resets HL count to 0, resets HH count to 0
LH fires → resets HH count to 0 only
HL fires → resets LL count to 0 only
```

**Why this matters:** A D LH after 3 D HHs means the bullish streak is broken. But a single D LH doesn't make it bearish — you need the context of where it sits.

---

## The Early Detection Principle

You don't wait for the parent TF zone to visually appear. The child TF zone comparison **is** the parent structure:

```
H1 makes HH (supply top > prev supply top)
  → IF that top also > prev H4 supply top
  → THEN H4 HH is confirmed NOW
  → Even though H4 HA color flip hasn't happened yet
```

**This is the core of early confirmation: child zone events = parent structure events.**
