## Build Order for Multi-Chart Analysis

### Layer 1: Foundation (understand the building blocks)
```
01_ZONE_CLASSIFICATION  →  Can I label every zone HH/HL/LH/LL?
02_STRUCTURE_PROPAGATION → Can I read parent structure from child zones?
```

### Layer 2: Counting (measure where we are)
```
03_ZONE_COUNTING  →  How many unbroken zones? Is impulse exhausted?
04_ZONE_NESTING   →  Are child zones inside parent zones? Same or opposing?
```

### Layer 3: Confirmation (detect what's happening)
```
05_TRENDLINE_BREAKS  →  Which TLs have broken? What does that confirm?
06_TERMINAL_EXHAUSTION → Is terminal active? Is the H4 zone live?
```

### Layer 4: Direction (know where to trade)
```
07_MACRO_BIAS      →  What's the confirmed direction?
08_ONE_TWO_THREE   →  Is a cascade compression building?
09_BOUNDARY_ZONES  →  Where's the structural decision point?
```

### Layer 5: Context (know what phase we're in)
```
10_D_LEVEL_CYCLE   →  Which of the 5 phases are we in?
EARLY_CONFIRMATION_CASCADE.md → Where's the earliest entry signal?
```

## Multi-Chart Panel Workflow

When you sit down at the charts, work top-down:

```
D panel:   What's D structure? (Rule 02) Is D LL/HH broken? (Rule 06)
H4 panel:  What's H4 doing? Push or pull? (Rule 02) Counter-zone? (Rule 06)
H1 panel:  Zone count? (Rule 03) Boundary? (Rule 09) Wave phase? (Rule 03)
M15 panel: Nested inside H1? (Rule 04) TL break? (Rule 05)
M5 panel:  Bias confirmation? (Rule 07) 1-2-3 cascade? (Rule 08)
M1 panel:  CHoCH for entry? (Early Confirmation Cascade)
```

## What to Keep vs Remove

Each file is independent. As you validate on chart:
- If a rule ADDS clarity → keep it, integrate into signal analysis
- If a rule is REDUNDANT with another → merge them
- If a rule NEVER produces useful signals on chart → remove it

The goal is: fewest possible rules that cover all tradeable scenarios.
