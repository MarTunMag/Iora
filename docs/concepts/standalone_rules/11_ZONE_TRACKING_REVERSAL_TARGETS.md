# Rule 11 — Zone Tracking & Reversal Target Identification

> **As price pushes, track the "last created zone" at each level.**
> The zone that caused the CHoCH at each level becomes the reversal target for the level above.
> This is how you know WHERE to exit and WHERE to enter the next trade.

---

## 1. The "Last Created Zone" Principle

As price pushes in one direction, each timeframe creates zones along the way. The rule is simple:

```
At every level, always track the LAST CREATED zone on each side.
The last created zone is the one that matters — it's the freshest structure.
```

| As price pushes DOWN through... | Track... | Why it matters |
|--------------------------------|----------|---------------|
| D zones | Last created D supply | This is the reversal target when D turns |
| H4 zones | Last created H4 supply | This is the D LH zone when H4 reverses up |
| H1 zones | Last created H1 supply | This is the H4 reversal target |
| M15 zones | Last created M15 supply | Entry/exit precision inside H1 |

**Mirror for push UP:** Track last created demand at each level.

---

## 2. The CHoCH Zone = Reversal Target for Parent

This is the critical extraction:

```
The H1 zone that CAUSED the H4 CHoCH = your reversal target
```

### How it works (bearish push example):

```
H4 is pushing down (making H4 LLs)
  → H1 supply zones are being created as price descends
  → At some point, H1 makes an HL instead of LL
    → This H1 HL = H4 HL (CHoCH at H4 level)
    → The H1 SUPPLY zone that was last created before this HL
      = the zone that "broke" to create the H4 HL
      = YOUR REVERSAL TARGET when price pushes back up
```

**In plain English:** When the H4 makes its HL, mark the H1 supply zone that was active when that happened. That's where you exit longs and look for shorts on the way back up.

## 3. The Full Cycle (Top-Down)

### Phase 1: Weekly Supply → Daily Push Down

```
W supply zone active (price rejected from weekly high)
  → D supply created as the first push down
    → TRACK: this D supply = last D supply
    → As D pushes lower, new D supply zones may form
    → Always update to the NEWEST D supply
```

### Phase 2: Daily Push → H4 Push Down

```
D supply pushes price down through H4 zones
  → H4 supply zones created as price descends
    → TRACK: last created H4 supply
    → H4 keeps making LLs (bearish impulse)
```

### Phase 3: H4 Push → H1 Push Down

```
H4 pushes price down through H1 zones
  → H1 supply zones created (LH tops = bearish TL)
    → TRACK: last created H1 supply
    → Count unbroken H1 supplies (Rule 03 — zone counting)
```

### Phase 4: H4 HL CHoCH (First Reversal Signal)

```
H1 makes an HL (instead of LL)
  → This H1 HL = H4 HL (CHoCH at H4)
  → MARK: the H1 supply that was last created BEFORE this HL
    → This is the "H4 HL break zone"
    → This H1 supply = YOUR REVERSAL TARGET for longs
```

### Phase 5: Continued Push Down After H4 HL

```
Even after H4 HL, the push can continue lower
  → H1 zones keep forming below
  → M15@H4 demand fires (M15 demand inside H4 demand)
    → This M15@H4 demand = bearish exhaustion / bullish confirmation
    → ENTRY: Long from this M15 demand (reversal entry)
```

### Phase 6: Push Up Into H1 Supply Target

```
Longs entered from M15@H4 demand
  → Price pushes up toward the H1 supply marked in Phase 4
  → Breaking the last created H1 supply (below the target)
    → Creates H4 HL CHoCH confirmation
    → M1 LL then M1 CHoCH (HL) while still inside M15 demand
      → This M15 demand persists as the D HL reversal zone
```

### Phase 7: H4 CHoCH Creates D Structure

```
Price pushes up into the H1 supply (the H4 HL break zone)
  → H4 makes HH or HL
  → But this H4 high is BELOW the last H4 supply
    → Therefore: D LH (not D HH)
    → D LH = bearish D structure intact
```

### Phase 8: Ride to D LH → Exit → Reverse

```
Push up continues to the H1 supply that created the H4 HL
  (the H4 impulse zone that broke D LL and confirmed D LL + W LL)
  → This is your D LH reversal zone
  → EXIT LONGS here
  → ENTER SHORTS via:
    → Sell limit at this H1 supply (Path D — bearish trigger)
    → M1 CHoCH add-on entries (Path E)
```

## 4. The "Don't Get Tricked by H4 HL" Rule

**Critical:** After a D LL break, the FIRST H4 zone on the opposite side is NOT your reversal target yet.

```
D LL breaks → new D LL + W LL confirmed
  → H4 starts pulling back (making H4 HLs)
  → FIRST H4 demand after break = important but NOT the reversal yet
  → You need the H4 HL to BREAK to create the D LL
  → Then the H4 supply ABOVE that break = the real reversal zone
```

### The rule:

```
After D LL break:
  → Track the HIGHEST H4 supply created during the push
    (this should be the FIRST H4 supply after the break)
  → The H4 HL must break first (pushing further down)
  → The H4 supply that caused the H4 HL break
    = the zone that pushed down to break D LL
    = YOUR D LH reversal target when price pushes back up
```

**Why you can get tricked:** The H4 HL looks like the market is reversing. But the D LL just broke — the H4 HL is just a correction in the push, not a reversal. The H4 HL needs to break to CONFIRM the D LL. Only after that break is complete do you have a clean reversal target.

---

## 5. The D LH Reversal Zone Identification

```
The D LH reversal zone is specifically:

  The H1 supply zone that was created as the H4 pushed
  to break the H4 HL, which then pushed to break the D LL,
  confirming the new D LL + W LL.

  → This H1 supply = narrowed-down D LH target
  → When price pushes back up here:
    → H4 HH forms (but below last H4 supply = D LH, not D HH)
    → Confirm reversal INSIDE this zone
    → Short entries from here
```

---

## 6. Weekly Context: Is This a D Pullback or W Continuation?

After riding the D LH push down to make new W LL + D LL:

```
Check: Is price inside the D demand that pushed for the last W HH?
  (through the W trendline push up)

IF YES → This D LL might be a W HL (weekly correction)
  → The D pullback we're in reverses
  → Continues to make new W HH → then W HL
  → Then pushes to make new Monthly HH or Monthly LH

IF NO → This is a W continuation lower
  → New W LL extends
  → Look for next D demand below as target
```

### The question at every D LL:

```
Is this D demand zone inside the W demand that built the last W push up?
  → YES = W HL likely = buy the D LL for W continuation
  → NO  = W impulse continuing down = sell the D HL
```

## 7. Zone Tracking Summary Table

| What to Track | When to Set It | What It Becomes |
|--------------|---------------|-----------------|
| Last D supply (as pushing down) | On each new D supply fire | D LH reversal zone (where shorts exit) |
| Last H4 supply (as pushing down) | On each new H4 supply fire | H4 reversal target for longs |
| H1 supply at H4 HL CHoCH | When H1 HL creates H4 HL | **Reversal target for longs** |
| H1 supply at H4 impulse D break | When H4 push breaks D LL | **D LH reversal zone** (exit longs, enter shorts) |
| First H4 supply after D LL break | On D LL break | Potential trap — wait for H4 HL break first |
| M15 demand @ H4 demand | On M15@H4 nesting | **Long entry zone** at terminal |
| D demand inside W demand | Check on D LL fire | Tells you if W reversal or W continuation |

## 8. The Mechanical Sequence (Entry to Exit to Re-Entry)

```
STEP 1 — IDENTIFY TERMINAL
  D LL broken, H4 demand below, H1 count 5+3
  → Terminal confirmed

STEP 2 — ENTER LONG
  M15 demand @ H4 demand (M15@H4 nesting)
  → M1 CHoCH (HL) inside M5 @ this M15 demand
  → LONG ENTRY

STEP 3 — TRACK REVERSAL TARGET
  Mark: H1 supply that created H4 HL break (= H4 impulse D break zone)
  → This is where you will EXIT LONGS

STEP 4 — RIDE TO TARGET
  Price pushes up through H1 zones
  → H4 HL → H4 HH (but below last H4 supply = D LH)
  → Approaching the marked H1 supply

STEP 5 — EXIT LONGS AT D LH ZONE
  Price enters the H1 supply marked in Step 3
  → EXIT LONGS (TP)

STEP 6 — ENTER SHORT
  Same zone: H1 supply = D LH reversal zone
  → Sell limit at this level (Path D)
  → M1 CHoCH add-on shorts (Path E)

STEP 7 — RIDE D PUSH DOWN
  D LH confirmed → aggressive push to new D LL + W LL
  → Mode B continuation shorts from M5/M15 supply

STEP 8 — CHECK WEEKLY CONTEXT
  At new D LL: is this inside W demand from last W push?
  → YES = W HL, prepare for reversal
  → NO = W continuation, ride further
```
