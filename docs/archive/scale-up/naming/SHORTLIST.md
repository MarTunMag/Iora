## Step 5: Availability Checks

### Bronnoysundregistrene (brreg.no)

Check if the company name is already registered in Norway.

| Name | Search URL | Available? | Date Checked |
|------|-----------|-----------|-------------|
| _______________ HOLDING AS | brreg.no/sok | [ ] Yes / [ ] No | |
| _______________ CAPITAL AS | brreg.no/sok | [ ] Yes / [ ] No | |
| (other entities) | | | |

**How to check:** Go to https://w2.brreg.no/enhet/sok/ and search for the name.

**Rules:**
- Name must not be identical or confusingly similar to an existing registered name
- Name must contain "AS" if it's an aksjeselskap
- Name cannot contain words implying government connection without approval
