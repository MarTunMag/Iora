# Corporate Empire Blueprint: Delegation & Entity Strategy

**Purpose:** Define the companies to create and consulting firms to engage so the founder can delegate operational tasks, maintain strategic oversight, and keep the full pipeline internal to the empire.

**Principle:** You are the architect, not the bricklayer. Every operational task should be delegated to either an internal entity or an external specialist. Your job is vision, capital allocation, and quality control.

**Disclaimer:** This is a strategic brainstorming document. All entity formation, regulatory licensing, and tax structuring must be validated by qualified professionals (forretningsadvokat, skatteadvokat, autorisert regnskapsforer) before action.

## 2. Entities to Create (Internal)

### 2.1 ARIS HOLDING AS — The Parent

**Purpose:** Own all subsidiaries. Centralize governance, capital allocation, and intercompany flows.

| Aspect | Detail |
|--------|--------|
| Type | Aksjeselskap (AS) |
| Role | Pure holding, board governance, strategic oversight |
| Revenue | Dividends from subsidiaries (fritaksmetoden on qualifying income) |
| You | Styreleder (Board Chair) + 100% shareholder |
| Create when | Phase B (NOK 500K-5M trading capital) |

**Why internal:** This is the keystone. It owns everything. No one else should own this.

---

### 2.2 ARIS CAPITAL AS — Trading Operations

**Purpose:** All algorithmic trading activity. P&L from V2 bots, future strategies, execution.

| Aspect | Detail |
|--------|--------|
| Type | AS, subsidiary of Holding |
| Revenue | Trading profits (forex, CFD, crypto) |
| Tax | 22% corporate on trading gains |
| Key staff | Quant developers, infrastructure engineers |
| Create when | Phase B (alongside Holding) |

**Why internal:** Core IP. The models, the edge, the infrastructure — this never leaves the family.

---

### 2.3 ARIS ASSET MANAGEMENT AS — Fund Management

**Purpose:** Manage external capital. Hedge fund / AIF (Alternative Investment Fund).

| Aspect | Detail |
|--------|--------|
| Type | AS with Finanstilsynet registration |
| Revenue | Management fee (1-2%) + performance fee (15-20%) |
| Regulation | AIF-forvalterforskriften (Norwegian AIF rules) — required above thresholds |
| Key staff | Compliance officer, fund admin, investor relations |
| Create when | Phase C-D (NOK 5M-50M, when ready for external capital) |

**Why internal:** Fee revenue stays in the group. External capital amplifies returns without risking personal capital. Same bots, same models, same infrastructure as Capital AS.

**External help needed:** Fund administrator (NAV calculation), fund legal counsel, compliance consultant.

---

### 2.4 ARIS INVEST AS — Equity Portfolio

**Purpose:** Long-term share portfolio benefiting from fritaksmetoden (near tax-free gains within AS).

| Aspect | Detail |
|--------|--------|
| Type | AS, subsidiary of Holding |
| Revenue | Share gains, dividends (nearly tax-free via fritaksmetoden) |
| Strategy | Index funds, individual equities, private equity, angel investments |
| Create when | Phase B-C (when trading generates excess capital to diversify) |

**Why internal:** The entire point is tax-efficient compounding inside the AS structure. Fritaksmetoden only works for qualifying entities (AS/ASA).

---

### 2.5 ARIS EIENDOM AS — Property

**Purpose:** Real estate acquisition, management, and development.

| Aspect | Detail |
|--------|--------|
| Type | AS, subsidiary of Holding |
| Revenue | Rental income, property appreciation |
| Strategy | Commercial and residential portfolios, development projects |
| Key staff | Property manager, accountant |
| Create when | Phase C (first property acquisition) |

**Why internal:** Property held inside AS has different wealth tax treatment. Keeps development profits internal. Pairs with Bygg AS for full vertical integration.

---

### 2.6 ARIS BYGG AS — Construction

**Purpose:** In-house construction and development capability.

| Aspect | Detail |
|--------|--------|
| Type | AS, subsidiary of Holding (or Eiendom) |
| Revenue | Construction contracts (primarily internal, can serve external) |
| Key staff | Project managers, site supervisors, subcontractor network |
| Regulation | Sentral godkjenning for construction (when applicable) |
| Create when | Phase C-D (when property development begins) |

**Why internal:** When Eiendom AS develops property, Bygg AS does the construction. Instead of paying 20-40% margins to external contractors, those margins stay in the group. Controls quality and timeline.

**External help initially:** Use external contractors for early projects. Form Bygg AS when volume justifies dedicated staff/equipment.

---

### 2.7 ARIS TECH AS — Technology & Shared Services

**Purpose:** Trading infrastructure, data services, SaaS products, IT for the group.

| Aspect | Detail |
|--------|--------|
| Type | AS, subsidiary of Holding |
| Revenue | Internal service fees + external SaaS licensing |
| Scope | Servers, data pipelines, monitoring, model deployment, group IT |
| Key staff | DevOps, data engineers, SRE |
| Create when | Phase C (when infrastructure needs exceed one person) |

**Why internal:** Technology is the group's competitive advantage. IP stays internal. Can license trading technology platform externally as additional revenue stream.

---

### 2.8 ARIS CONSULTING AS — Advisory Services

**Purpose:** Internal professional services (legal, tax, compliance, strategy). Can serve external clients.

| Aspect | Detail |
|--------|--------|
| Type | AS, subsidiary of Holding |
| Revenue | Internal advisory fees + external consulting |
| Scope | Tax planning, legal coordination, compliance, M&A advisory |
| Key staff | In-house counsel, tax advisor, compliance manager |
| Create when | Phase D (when group complexity justifies dedicated staff) |

**Why internal at scale:** Instead of paying NOK 2,000-5,000/hour to external law firms for every question, hire dedicated professionals who understand the group. Keeps institutional knowledge internal. Can also serve external clients (additional revenue).

**Until then:** Outsource to external firms (see Section 3).

---

### 2.9 ARIS STIFTELSE — Foundation

**Purpose:** Philanthropy, community impact, education programs.

| Aspect | Detail |
|--------|--------|
| Type | Stiftelse (foundation, non-profit) |
| Governance | Independent board (required by Stiftelsesloven) |
| Funding | Annual contributions from Holding or subsidiaries |
| Tax | Tax-deductible donations up to NOK 50,000/year (current limit) |
| Create when | Phase C (even at 1-2% of profits) |

**Why separate entity:** Stiftelser have specific legal requirements and governance in Norway. Independent from the commercial group, but funded by it.

2. Find an accountant comfortable with financial instruments (Leinonen or ybiN are good candidates)
3. Give them the structured output (JSON/CSV/TXT) so they don't have to understand your bots — just the P&L numbers
4. The skatterapport TXT file we generate is literally written for this purpose

## 7. Norway-Specific Considerations

### Entity Registration

- All AS entities registered at **Brønnøysundregistrene** via Altinn
- Each AS requires NOK 30,000 share capital + NOK 6,825 registration fee
- Single shareholder (you via Holding AS) is fine
- No auditor required if: revenue <NOK 7M, assets <NOK 27M, <10 employees

### Intercompany Transactions

- Must be at arm's length (armlengdeprinsippet)
- Transfer pricing documentation required for significant internal transactions
- Dividends between group companies: fritaksmetoden (near tax-free)
- Management fees from Holding to subsidiaries are common and accepted

### Fund Regulation (Kaizen Asset Management)

- **AIF-forvalterforskriften** — Norwegian implementation of EU AIFMD
- Below threshold (EUR 100M, or EUR 500M without leverage): registration only
- Above threshold: full license from Finanstilsynet
- Compliance, risk management, depositary requirements increase with scale

### Construction (Aris Bygg AS)

- **Sentral godkjenning** (central approval) from DIBK required for certain building categories
- Responsible applicant (ansvarlig søker) role needs qualified individuals
- Can start without sentral godkjenning using local approval (ansvarsrett)

### Stiftelse (Foundation)

- Governed by **Stiftelsesloven** (Foundation Act)
- Must have independent board (you cannot be sole board member)
- Irrevocable — capital donated to the foundation cannot be withdrawn
- Registered with Stiftelsestilsynet
- Tax-deductible donations from companies: up to NOK 50,000/year (2026)
