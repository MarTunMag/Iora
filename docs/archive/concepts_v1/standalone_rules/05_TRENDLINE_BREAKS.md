# Rule 5 — Trendline Breaks (Push Completion Signals)

> **Each TL break confirms one level up is done.**
> Impulse TL break = potential reversal. Correction TL break = trend resumes.

---

## How TLs Are Built

**Bearish TL:** Connects consecutive LH supply zone tops (descending resistance)
**Bullish TL:** Connects consecutive HL demand zone bottoms (ascending support)

Each new LH/HL redraws the TL from the anchor through the latest point.

---

## What Each Break Confirms

| TL that breaks | What it confirms |
|---------------|-----------------|
| M5 TL break | M15 sub-wave complete |
| M15 TL break | **H1 push complete** |
| H1 TL break | **H4 push complete** |
| H4 TL break | **D leg complete** |

---

## Impulse vs Correction TL

| TL Type | Connects | Style | Break means |
|---------|----------|-------|-------------|
| **Impulse** (solid) | HH tops or LL bots | Thick, solid | **Potential reversal** — trend push broke |
| **Correction** (dashed) | LH tops or HL bots | Thin, dashed | **Trend resumes** — pullback failed |

### Reading the cascade on chart:

```
H4 impulse TL descending (LH supply tops going lower)
  → H4 correction TL ascending (HL demand bots going higher)
    → Correction TL breaks DOWN = impulse resumes = new push leg
    → Impulse TL breaks UP = potential D reversal
```

---

## Break Detection

```
Bearish TL break:  high > interpolated TL price  (price above descending resistance)
Bullish TL break:  low  < interpolated TL price  (price below ascending support)
```

Fires once per TL. Resets when TL is archived (on HH/LL) or redrawn (new LH/HL).

---

## What to Look For on Chart

**Single panel, one TL at a time:**

1. Is there an active bearish TL? (descending line connecting LH supply tops)
2. Is there an active bullish TL? (ascending line connecting HL demand bots)
3. Has price broken through either?

**The key question:** Is this an impulse TL break or a correction TL break?
- Impulse break → big signal, structure changing
- Correction break → continuation, trend resumes

---

## The M15 TL Break Is Your Entry Gate

For most entries in the system, the M15 TL break is the confirmation that the H1 sub-wave is complete. It's used as a prerequisite in:

- Path A (Terminal reversal): M15 bear TL break required
- Path B (H1 stair-step): M15 bull TL break as pullback exhaustion
- Early confirmation cascade: M15 CHoCH + TL break = H1 leg done
